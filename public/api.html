01 / GET CONNECTED

Start with one request

Read the last 24 hours of data for every algorithm. No account, API key, or authentication header is required.

cURLOpen JSON ↗
curl -fsS 'https://vergecurrency.network/api/dashboard'
JavaScript example · Node.js or a page on this origin
const end = new Date();
const start = new Date(end.getTime() - 60 * 60 * 1000);
const url = new URL('https://vergecurrency.network/api/dashboard');
url.search = new URLSearchParams({
  from: start.toISOString(),
  to: end.toISOString(),
  bucket: 'auto'
});

const response = await fetch(url);
const data = await response.json();
if (!response.ok) throw new Error(data.error);

console.log(data.datasets.hashpower.latest?.scrypt);
console.log(data.datasets.difficulty.points);

The API is public, but cross-origin browser requests are not enabled. Use a server-side client to fetch it from another website, or call it from a page on this origin.

02 / TWO ENDPOINTS

Choose your signal

GET/api/dashboard↗

Returns both hashpower and difficulty, including chart points and the latest recorded sample within your chosen dates. Every response contains all five algorithms; select the fields you need in your client.

GET/api/health↗
{"status":"ok","mode":"live"}

This confirms the web process is responding. It does not check whether new mining samples are being collected. Check sample timestamps in the dashboard response for freshness.

Both endpoints also accept HEAD. Requests are read-only; other HTTP methods are rejected.

03 / SET THE WINDOW

Date ranges & grouping

Add these query parameters to /api/dashboard. Omit the dates for the last 24 hours, or supply both dates together.

ParameterFormatBehavior
fromISO UTC stringStart date, inclusive. Example: 2026-11-05T12:00:00Z.
toISO UTC stringEnd date, inclusive. Must follow from. Choose dates ending at or before now.
bucketauto, hour, day, monthOptional, defaults to auto. Controls the averaging interval.
GroupingValues returnedMaximum date span
autoAbout 360 averaged points, with a minimum interval of one minute.20 years
hourHourly averages.31 days
dayDaily averages.744 days
monthActual calendar-month averages, weighted by sample count.20 years

Dates must include the time and end in Z; optional fractional seconds are supported. Hour, day, and month boundaries use UTC. Only from, to, and bucket are accepted, once each. There is no algorithm, period, or arbitrary query parameter.

04 / THE FIVE ALGORITHMS

Know your fields

Hashrate uses raw hashes per second (H/s). Difficulty is dimensionless. Grouped values are averages and may be fractional.

AlgorithmInside datasets.hashpowerInside datasets.difficulty
Scryptscryptscrypt
Groestlgroestlgroestl
Lyra2RElyra2relyra2re
X17x17x17
Blake2sblake2sblake

The Blake field names differ between the two metrics. A value of null means no recorded value; it is not a zero. Each point's time is a Unix timestamp in milliseconds: use new Date(point.time) in JavaScript.

05 / READ THE RESPONSE

Data & freshness

PropertyMeaning
modelive means real recorded data, not a guarantee it is current. demo identifies generated preview data.
generatedAtISO UTC time this response was generated. A cached response retains its original time.
rangeEffective from, to, intervalMs in milliseconds, and the selected grouping. Monthly grouping combines daily samples into calendar months.
availableRangeKnown recorded history as {from, to} in milliseconds, or null if none is known or metadata is unavailable.
datasetsContains hashpower and difficulty. Each has points (averaged rows), latest (the latest raw sample in your dates, or null), and available (whether its queries succeeded).
partialtrue when one metric could not be loaded. An empty period alone does not make a result partial.
latestObservedAtNewest raw sample timestamp in the selected range, in milliseconds, or null. Use this to evaluate freshness for a current period.
Empty date ranges stay empty. Missing fields remain null; clients should not replace them with zero. Historical backfilled snapshots may be less frequent than live samples.

07 / KEEP THE SIGNAL CLEAR
Usage & errors
Poll at most once per minute. Chart requests are limited to 12 per 10 seconds per client IP address; clients sharing an address share that allowance. Identical date ranges may be cached for 30 seconds, and history metadata for up to one minute.

          
StatusMeaning

            
200Successful response, including valid periods with no recorded samples. Check partial and each metric's available flag.

            
400Invalid dates, grouping, unknown parameters, or repeated parameters.

            
404Unknown route.

            
405Unsupported HTTP method. Use GET or HEAD.

            
429Rate limited or temporarily busy. Honor Retry-After when present and back off before retrying.

            
503Statistics temporarily unavailable. Retry later.

          

          
Errors use a JSON object with an error message:
{"error":"Provide both from and to dates."}
